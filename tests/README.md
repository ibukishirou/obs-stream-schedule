# ブラウザ検証

```sh
npm install
npx playwright install chromium
npm test
```

インストール済みの Chrome を使う場合は環境変数 `BROWSER_CHANNEL=chrome` を指定します。

検証対象：翌日への移動による先週の同曜日の複数予定コピー、コピー元の独立性、入力済み予定の保持、削除後・再読み込み後の再コピー防止、年またぎ、先週に予定がない場合、280px 幅のタブ、キーボード操作、設定の保存、横・縦テーマでの最長タイトルと共通幅、揃え方、背景幅、表示対象外のタイトルの除外、手動横幅への復帰、予定がない場合。

環境変数 `SAMPLE_DIR` を指定すると、実際の `view.html` の表示を元に左揃え・中央揃えの比較 HTML と PNG を出力します。比較のため、通常は順番に切り替わる2件の予定を上下に並べています。
